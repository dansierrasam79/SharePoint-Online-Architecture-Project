# SharePoint Junction
A portfolio-grade SharePoint Online Information Governance and Records Management platform aligned with ISO 15489 principles.

## Overview
SharePoint Junction demonstrates the design and implementation of a modern Microsoft 365 information management solution for a fictional Testing & Quality Engineering organization.

The solution showcases:
- SharePoint Information Architecture
- Records Management
- Document Management
- Metadata and Taxonomy
- Governance
- Hub Site Architecture
- Search Optimization
- Power Automate Integration
- Copilot Readiness
