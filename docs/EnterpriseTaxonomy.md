# Enterprise Taxonomy

## Purpose

The Enterprise Taxonomy defines the controlled vocabulary used across
QualityFirst Technologies SharePoint Online.

The taxonomy supports:

- Information Architecture
- Content Classification
- Search
- Records Management
- Retention
- Power Automate
- Copilot Readiness
